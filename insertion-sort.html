Insertion Sort is an algorithm that maintains a sorted portion of the array and inserts each new element into the correct position of the sorted section.
function startSort() { if (isSorting) return; if (currentArray.length < 2) { alert('请输入至少2个数字！'); return; } isSorting = true; const speed = parseInt(document.getElementById('speedControl').value); const arr = [...currentArray]; const n = arr.length; let sortedCount = 1; ... for (let i = 1; i < n; i++) { let key = arr[i]; let j = i - 1; while (j >= 0 && arr[j] > key) { arr[j + 1] = arr[j]; j = j - 1; } arr[j + 1] = key; } renderBars([], -1, [...Array(n).keys()]); document.getElementById('output').textContent = '✅ 排序完成！结果：' + currentArray.join(', '); isSorting = false; }

Step-by-step:

1) Assume the first element is sorted;

2) Take the next element as key, compare it leftward in the sorted section;

3) If the left element > key, shift it right;

4) Insert key into the correct position and extend sorted section;

5) Repeat until the whole array is sorted. Complexity: O(n²) time, O(1) space.
