## Bubble sorting method<br>
Bubble Sort operates on the principle of repeated neighbor comparison. It traverses the array multiple times, comparing adjacent elements and swapping them if they are in the wrong order; this causes the largest values to "bubble up" to the end of the list with each pass.<br>
## Selection Sort<br>
Selection Sort, conversely, is based on finding the minimum element from the unsorted portion of the list. It scans the unsorted section to identify the smallest value and swaps it with the element at the current boundary of the sorted section, effectively "selecting" the correct item for each position one by one.
## Insertion sort<br>
Insertion Sort is an intuitive sorting algorithm that works similarly to the way you might sort playing cards in your hands. You pick one card at a time and "insert" it into its correct position relative to the cards you are already holding.<br>
## Merge sort method
A "divide and conquer" algorithm that recursively splits the array into two halves until each sub-array contains only one element. It then merges those sub-arrays back together in sorted order.
## XXX sorting method or Quick sort
Often used as the standard "efficient" sort, it picks a "pivot" element and partitions the array so that elements smaller than the pivot move to the left and larger ones move to the right. It then recursively sorts the sub-arrays.
## Comprehensive comparison
Choosing the right algorithm depends on the constraints of the system. Bubble and Selection sorts are rarely used in production due to their $O(n^2)$ nature but are excellent for educational purposes. Insertion Sort is surprisingly fast for small arrays ($n < 15$) and is often used as a fallback for more complex algorithms. Merge Sort is highly stable and predictable but requires extra memory, whereas Quick Sort is usually the fastest in practice for large datasets, despite its theoretical worst-case.
